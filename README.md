# mg

Desarrollador full stack. Trabajo con Vue y PHP en la web, y con C# en aplicaciones de escritorio para Windows.

## Stack

- **Frontend:** Vue 3, JavaScript, HTML, CSS
- **Backend:** PHP, Node.js
- **Base de datos:** MySQL
- **Escritorio:** C#, WPF, .NET
- **Herramientas:** Git, VS Code, Visual Studio, PowerShell

## Proyectos

### [Gymtrack](https://github.com/5-mg/Gymtrack)
Plataforma de gestión de gimnasios. Vue 3, PHP y MySQL.

### [OpenCube](https://github.com/5-mg/OpenCube)
Herramienta de mantenimiento para Windows 11, transparente y reversible. C# y WPF.
